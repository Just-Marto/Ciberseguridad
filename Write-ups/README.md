# Writeups

**EN** — Machine and challenge write-ups. Focusing on methodology and reasoning, not from the command sequence.

**ES** — Writeups de máquinas y desafíos. El foco está en la metodología y el razonamiento, no en la secuencia de comandos.


## Structure
 
Each subfolder corresponds to a platform or source of challenges. Inside each one, individual write-ups are organized per machine/lab.
